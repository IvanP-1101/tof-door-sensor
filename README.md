# ToF Door Sensor for Home Assistant
Лазерный ToF-датчик на ESP32-C3. Крепится на косяк двери и служит для мгновенного включения света в комнате в момент прохождения человеком дверного проёма. Работает с Home Assistant через ESPHome.

Проект разработан для устранения задержки обнаружения, которая присутствует у большинства датчиков присутствия (вроде Aqara FP2) и обычных PIR-датчиков движения.

## 🛠 Технические особенности
* **База:** Микроконтроллер ESP32-C3 SuperMini + лазерный дальномер VL53L1X (Time-of-Flight).
* **Логика:** Датчик аппаратно опрашивается каждые 50 мс. В коде настроен фильтр дельты на 3.5 см, что полностью отсекает естественный микрошум лазера и исключает лишнюю нагрузку на Wi-Fi сеть. Максимальное измеряемое расстояние ограничено 130 см (режим работы Short).
* **Сборка:** Нужно спаять между собой модули по шине I2C (SDA, SCL, VCC, GND). Крышку необходимо приклеить к корпусу супер клеем или жидким скотчем.

## 🔌 Подключение к сети (Wi-Fi)
Интеграция устройства происходит полностью нативно. При первом включении датчик автоматически поднимает собственную точку доступа Wi-Fi (Captive Portal). Достаточно подключиться к ней со смартфона, выбрать свою домашнюю сеть и ввести от неё пароль. После сохранения датчик перезагрузится и подключится к локальной сети, где Home Assistant сразу обнаружит его как новое устройство.


## 📂 Что в репозитории
* `Door_Sensor.yaml` — готовый конфигурационный файл для прошивки через ESPHome.
* `Door_Sensor (Корпус).stl` и `Door_Sensor (Крышка).stl` — модели корпуса для самостоятельной печати на 3D-принтере.
